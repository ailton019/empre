# Aion ERP — Site Oficial (by AionLabs)

Repositório do site oficial do **Aion ERP**, plataforma de gestão empresarial desenvolvida pela **AionLabs**.

- **URL de Publicação:** [https://ailton019.github.io/empre/](https://ailton019.github.io/empre/)
- **Slogan:** *"Um único sistema. Diversos segmentos."*

## Estrutura do Projeto

- `index.html` — Página principal do produto Aion ERP (Hero, Benefícios, Funcionalidades com capturas reais do sistema, Segmentos, Como Funciona, Diferenciais, Planos e Condições Comerciais, FAQ, Chamada para Ação e Formulário de Demonstração).
- `politica-de-privacidade.html` — Política de Privacidade institucional.
- `termos-de-uso.html` — Termos e Condições de Uso da plataforma.
- `assets/favicon.png` — Ícone da marca Aion ERP (símbolo geométrico em camadas).
- `assets/og-aion-erp.png` — Imagem de compartilhamento Open Graph (WhatsApp, LinkedIn, Instagram).
- `assets/screenshots/` — Capturas de tela autênticas dos módulos implementados no Aion ERP (`dashboard.png`, `clientes.png`, `produtos.png`, `estoque.png`, `vendas_pdv.png`, `contas_receber.png`, `despesas.png`, `agendamentos.png`, `relatorios.png`, `login.png`).
